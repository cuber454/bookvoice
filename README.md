# BookVoice

Читалка книг вслух для незрячих и слабовидящих. Приложение для Android,
управляется жестами и экранным диктором TalkBack.

## Что умеет

- Читает книги любым системным голосом: скорость, тон и громкость настраиваются.
- Прямую речь можно читать вторым голосом — диалоги звучат иначе, чем слова автора.
- Словарь произношения: свои правила «что искать — на что менять».
- Форматы: FB2, EPUB, TXT, PDF, DOCX, ODT, HTML.
- Сетевые библиотеки (OPDS): поиск и скачивание книг.
- Синхронизация и резервные копии: места чтения, закладки, цитаты.
- Таймер сна, управление гарнитурой, автопрокрутка.
