# BookVoice

Читалка книг для незрячих пользователей, управление голосом TalkBack. Kotlin без
Compose: обычные Activity, XML-разметка, viewBinding.

## Параметры
- applicationId и namespace `com.cuber.bookvoice`, compileSdk и targetSdk 36,
  minSdk 24, JVM target 17.
- AGP 9.0.1 со встроенной поддержкой Kotlin: отдельный плагин kotlin-android не
  подключается, jvmTarget берётся из compileOptions.
- gradle-wrapper.properties в репозитории указывает на Gradle 8.9, для AGP 9 это
  мало. Локально собирать системным Gradle 9.7.1 (scoop), а не `.\gradlew.bat`.
  На CI ставится Gradle 9.1 и вызывается напрямую.
- Зависимости: okhttp 4.12.0, appcompat 1.7.0, material 1.12.0, androidx.media 1.7.0,
  androidx.activity 1.9.3, pdfbox-android 2.0.27.0.
- Версия 0.4.87, versionCode 147. Тег релиза = "v" + versionName.

## Сборка
- Переменные: `GRADLE_USER_HOME=D:\Android\android-hello\.gradle-home`,
  `ANDROID_HOME=C:\AndroidSDK`.
- Команда из корня проекта:
  `gradle --no-daemon --console=plain :app:assembleDebug`
- Результат: `app\build\outputs\apk\debug\app-debug.apk`.
- Собранный файл сразу отправлять в Телеграм этим же чатом (sendDocument), а не
  только оставлять на диске: Серж проверяет сборки с телефона.
- Путь к SDK лежит в local.properties (в git не хранится).
- В песочнице DSH сборка проходит только с расширенным доступом: в обычном режиме
  не стартует процесс сборки Gradle.

## Git и подпись
- Репозиторий клонирован с повышенными правами, поэтому git зовём с
  `-c safe.directory='*'`, иначе он ругается на dubious ownership.
- Проверено 26.09.2026 ключом `apksigner` (build-tools 36.0.0): все APK, которые
  уходили тестерам (dist\0.4.57 … 0.4.82), и все релизы на GitHub подписаны одним
  ключом, отпечаток сертификата SHA-256
  `81:B4:9C:78:8D:67:F7:06:65:09:58:06:ED:B9:96:5D:E2:EE:1F:9E:93:C2:03:86:69:50:9C:AF:77:81:B9:4C`.
  Это ключ из секрета репозитория `DEBUG_KEYSTORE_B64` (шаг «Restore debug
  keystore» в `.github/workflows/build-apk.yml`, заведён 07.09.2026): сборка на
  GitHub подписывает APK именно им, поэтому релиз встаёт поверх тестерской
  сборки без удаления приложения.
- Сборка на этой машине (`gradle :app:assembleDebug`) берёт обычный
  `~\.android\debug.keystore`, а он ДРУГОЙ (отпечаток
  `AF:3E:DE:A0:89:24:00:95:C5:2D:F0:65:74:54:98:7C:25:AD:16:3D:43:06:04:F1:97:79:7A:32:DA:8D:D2:AE`).
  Такой APK поверх тестерского или релизного не встанет: Android откажет по
  несовпадению подписи, придётся удалять приложение (вместе с настройками).
  Поэтому локальная сборка годится для проверки на чистом устройстве или после
  удаления, а тестерам отдаём APK, собранный GitHub Actions.
- Ключа из секрета на машине нет: в `~\.android` лежит только локальный debug.
  Если понадобится собирать «тем самым» ключом локально, его надо положить
  отдельным файлом и подключать своей `signingConfig`, а не подменять
  `~\.android\debug.keystore`.

## Термины
- Меню, в котором диктор показывает наши именованные действия, называем как у
  Гугла: «меню TalkBack, пункт „Действия“». Открывается тремя пальцами по экрану.
  Старое название «локальное контекстное меню» (свайп вверх, затем влево) не
  используем: в новых версиях TalkBack его слили с меню TalkBack.
